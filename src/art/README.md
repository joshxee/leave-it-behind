# art

The prototype art packs, as the game uses them. Infrastructure, not a feature: `ArtPlugin` loads the character and tile atlases plus the maintenance sheets (nearest sampling, so pixels stay crisp) into the `Art` resource, and the modules hold the manifest data the game needs.

| Pack | Source (`assets/`) | Here |
|---|---|---|
| Derelict ship tiles: 64 tiles of 64×64 | `environment/derelict-ship/` (`ship-atlas.png`, `manifest.json`) | `tiles.rs`: `Tile` (atlas order), collision boxes, interaction points, variants (`Tile::wall(mask)`, `door`, `breach`, `patched`, `cockpit`, `diagnostic`) |
| Derelict engineer: 192 frames of 64×64 | `characters/engineer/` (`engineer-atlas.png`, `manifest.json`) | `engineer.rs`: `Action` (idle, walk, wrench/tape hold, use and walk), atlas indices, `facing` (16/8 directions), tool `contact` points, the feet pivot `ROOT` / `ANCHOR` |

- **Scale:** tiles and characters use one art pixel per world unit; a tile is 64 units. The radar housing fills the map’s display region.
- **Kept in step:** unit tests read each pack's `manifest.json` (`serde_json`, dev-only) and check every atlas index, collision box, interaction point and contact point. When a pack changes, run the tests; they say what moved.
- **Runtime files:** builds copy only `assets/RUNTIME_ASSETS` (`scripts/stage-assets.sh`); a test checks every path the game loads is listed there and exists.
- **Changing art:** each pack is generated by its `source/build.lua` (sprite-axi + Aseprite) and checked by its `source/validate.cjs`; see the pack's README. Never edit the PNGs by hand.
- **Placeholders:** remaining shapes (bunk and snap ring) are shapes in the pack palette (`palette.rs`), listed in `docs/ART_REQUESTS.md`.
- **Headless:** without an `AssetServer` (tests) `Art` holds default handles, which is fine because nothing renders.
- **Tests:** unit tests in `tiles.rs`, `engineer.rs`, `mod.rs`.

`maintenance.rs` loads the radar, ship cursor, engine assemblies, threaded bolts, woven tape, breaches and full-height wall/door sheets. Its cell sizes and frame counts are checked against `assets/maintenance/manifest.json`; nearest sampling and default handles work in both rendered and headless apps.
