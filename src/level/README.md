# level

The flight: countdown to arrival, the level's fault schedule, the damage faults do, and the outcome. `AppState::Landed` when the countdown hits zero (victory), `AppState::Lost` when any fault's clock runs out. The end screen (`menu`) flies again (R) or goes to the main menu; a fresh run is `OnEnter(Playing)` despawning every `RunEntity` and resetting every run resource.

- **Damage and the best flight (`progress.rs`):** `Damage { oxygen, course, engine }` is how long each kind of fault ran before it was fixed (breaches lose oxygen, drift goes off course, loose bolts overheat the engine), added up every tick by `track_damage`. A finished flight is a `RunRecord { landed, damage, survived }`: landing beats losing, then the least total damage wins; between losses, the longest flight. Compared in the whole seconds the end screen shows. `Progress` keeps flights, landings and the best record per level id (`LevelDef::id`; never change a released id) and is saved by `save`. `LastRun` is the flight that just ended and whether it is a new best.

- **Level format (`def.rs`):** `LevelDef { id, name, duration_secs, seed, envelope, slots, coaching }`. A `FaultSlot` has a timing `window`, weighted `choices` (kind, optional pinned site) and a failure-`clock` window. `roll(&mut GameRng)` turns slots into `PlannedFault { at, site, clock }`; pinned values draw no randomness. `validate()` checks durations, weights, site kinds, windows and clocks (55–90 s), and that the worst case over every possible roll stays inside the `Envelope { max_overlap, response_secs }` (faults needing handling at once, each busy for `response_secs`). It also checks that, each fault handled within `response_secs`, no roll could spend the oxygen or the engine's heat (`worst_case_strain`, `LevelError::Pool`): every slot that may roll the kind drains for the whole response at its shortest clock, and the pool refills only in gaps no roll can close. A slot's clock is its failure clock for drift and its drain for breaches and bolts (seconds to spend a full pool alone; see `faults`). A slot whose site is still busy waits until it is free. `coaching` coaches first-time players through the level (`coach`).
- **Level one (`one.rs`):** fully pinned (every slot exact, `seed` fixes drift headings): 4:30 flight, 10 faults, clocks 68–86 s. 0:10–1:30 one at a time (each kind once), 1:36–2:40 two at once, 2:56–3:06 all three at once, spread tip to tail. Needs 12 s of the 20 s tape roll. Breach and bolt clocks drain the oxygen and engine heat, so a slow fix leaves less for the next fault of its kind; the breaches (0:38, 1:36, 2:20, 3:01) sit far enough apart for the air to refill if each is fixed in 20 s. Tuned when the ship pointed right (helm to airlock about 15 s at `PLAYER_SPEED`); pointing up it is about 9.5 s, so with the same schedule the level plays easier than tuned. Retune here once the layout settles.
- **Launch:** the countdown and the fault schedule wait while `Journey::launched` is false. Every flight launches at once, except level one's first, which the pre-flight check holds (`coach`).
- **Resources:** `CurrentLevel`, `Journey { duration, elapsed, launched }`, `FaultPlan { pending }`, `RunStats { started, fixed, failure, damage }`, `Progress`, `LastRun`.
- **Systems:** `start_run` (`OnEnter(Playing)`: reseed, roll, reset), `advance_journey` → `start_due_faults` → `track_damage` (FixedUpdate/Simulate), `count_fixes` → `decide_outcome` (FixedUpdate/Resolve, after `resolve_faults`), `record_run` (`OnEnter(Landed)`, `OnEnter(Lost)`).
- **Functions:** `format_clock`, `peak_overlap`, `damage_secs`, `flight_secs`.
- **Tests:** unit tests in `def.rs`, `one.rs`, `progress.rs`, `mod.rs`; integration tests in `tests/integration/level.rs` (schedule, determinism, landing, loss, a full run fixing every fault in 20 s, restart) and `tests/integration/save.rs` (damage, recording the best); e2e in `e2e/specs/outcome.spec.ts`.
- **Scenarios:** `default`, `landing`, `breach_critical`.
