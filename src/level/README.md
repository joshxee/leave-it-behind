# level

The flight: countdown to arrival, the level's fault schedule, the damage faults do, and the outcome. `AppState::Landed` when the countdown hits zero (victory), `AppState::Lost` when any fault's clock runs out. The end screen (`menu`) continues to the next level after a landing (by way of an upgrade), flies again (R) or goes to the main menu; a fresh run is `OnEnter(Playing)` despawning every `RunEntity` and resetting every run resource.

- **Damage and the best flight (`progress.rs`):** `Damage { oxygen, course, engine }` is how long each kind of fault ran before it was fixed (breaches lose oxygen, drift goes off course, loose bolts overheat the engine), added up every tick by `track_damage`. A finished flight is a `RunRecord { landed, damage, survived }`: landing beats losing, then the least total damage wins; between losses, the longest flight. Compared in the whole seconds the end screen shows. `Progress` keeps flights, landings and the best record per level id (`LevelDef::id`; never change a released id) and is saved by `save`. `LastRun` is the flight that just ended and whether it is a new best.

- **Level format (`def.rs`):** `LevelDef { id, name, duration_secs, seed, envelope, slots, coaching }`. A `FaultSlot` has a timing `window`, weighted `choices` (kind, optional pinned site) and a failure-`clock` window; `FaultSlot::pinned` pins all three, `FaultSlot::any(window, kinds, clock)` offers any site of the listed kinds with equal odds. `roll(&mut GameRng)` turns slots into `PlannedFault { at, site, clock }`; pinned values draw no randomness, and an unpinned site is any of its kind's sites, equally likely. `validate()` checks durations, weights, site kinds, windows and clocks (55–90 s), and that the worst case over every possible roll stays inside the `Envelope { max_overlap, response_secs }` (faults needing handling at once, each busy for `response_secs`). It also checks that, each fault handled within `response_secs`, no roll could spend the oxygen or the engine's heat (`worst_case_strain`, `LevelError::Pool`): every slot that may roll the kind drains for the whole response at its shortest clock, and the pool refills only in gaps no roll can close. A slot's clock is its failure clock for drift and its drain for breaches and bolts (seconds to spend a full pool alone; see `faults`). A slot whose site is still busy waits until it is free. `coaching` coaches first-time players through the level (`coach`).
- **The campaign (`campaign.rs`):** five levels flown in order (`campaign`, `level(n)`, `number_of(id)`, `next_after(id)`, `LEVEL_IDS`, `LEVEL_COUNT`), an upgrade picked between each (`upgrades`, chosen on the `menu`'s upgrade screen). Levels two to five are unseeded and randomized within their windows; each slot names the kinds it may be, so every level has every kind, never needs more than 15 s of the 20 s tape roll, and (`validate`) can never spend the oxygen or the engine's heat when each fault is fixed within 20 s.

  | Level | Flight | Faults | At once | Clocks |
  |---|---|---|---|---|
  | 1 | 2:30 | 4 | 1 | 55–80 s |
  | 2 | 3:30 | 6 | 1 | 55–75 s |
  | 3 | 3:45 | 8 | 2 | 55–70 s |
  | 4 | 4:00 | 11 | 3 (once) | 55–68 s |
  | 5 | 4:30 | 14 | 3 (twice) | 55–65 s |

- **Level one (`one.rs`):** 2:30, teaches the three fixes. Pinned: loose bolts at 0:10 (port engine, spine side), a breach at 0:34 in the same engine room, drift at 0:58; then one more fault of a random kind and site at 1:24–1:30, so one fix is done twice. Never two at once. Unseeded, so the last fault (and the drift heading) differ from run to run. Every fault in every level can fail before landing (unit-tested).
- **Launch:** the countdown and the fault schedule wait while `Journey::launched` is false. Every flight launches at once, except level one's first, which the pre-flight check holds (`coach`).
- **Resources:** `CurrentLevel` (`number`, `next`), `Journey { duration, elapsed, launched }`, `FaultPlan { pending }`, `RunStats { started, fixed, failure, damage }`, `Progress`, `LastRun`.
- **Systems:** `start_run` (`OnEnter(Playing)`: reseed, roll, reset), `advance_journey` → `start_due_faults` → `track_damage` (FixedUpdate/Simulate), `count_fixes` → `decide_outcome` (FixedUpdate/Resolve, after `resolve_faults`), `record_run` (`OnEnter(Landed)`, `OnEnter(Lost)`).
- **Functions:** `format_clock`, `peak_overlap`, `damage_secs`, `flight_secs`.
- **Tests:** unit tests in `def.rs`, `one.rs`, `campaign.rs`, `progress.rs`, `mod.rs`; integration tests in `tests/integration/level.rs` (schedule, the pinned first three faults, landing, loss, a full run fixing every fault in 20 s, restart), `tests/integration/campaign.rs` (landing to the upgrades to the next level, the last level, a new game, every level landing with 20 s repairs) and `tests/integration/save.rs` (damage, recording the best); e2e in `e2e/specs/outcome.spec.ts`.
- **Scenarios:** `default`, `landing`, `breach_critical`, `level_five`, `final_landing`.
